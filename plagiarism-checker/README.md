# TextTrace EDU

Данный комплект содержит браузерное расширение для анализа документов курсовых работ и локальный сервер обработки файлов. Проверка выполняется на компьютере пользователя: расширение отвечает за интерфейс и локальную историю, сервер извлекает текст из документа и сравнивает его с уже загруженными работами.

## Структура

```text
chrome_extension   расширение, которое загружается в браузер
server_node        Node.js сервер анализа документов
test_files         файлы для демонстрационной проверки
vue_source         исходные Vue-компоненты интерфейса
PROJECT_NOTES.txt  краткая информация о варианте
```

## 1. Поднять серверную часть

Перейди в каталог сервера:

```powershell
cd "D:\уник\3 курс\2 сем\WEB\6\plagiarism-checker\server_node"
```

Запусти сервер:

```powershell
node src/server.js
```

Адрес сервера для этого варианта:

```text
http://localhost:3100
```

Быстрая проверка:

```text
http://localhost:3100/api/health
```

Ожидаемый результат - JSON-ответ со статусом `ok`.

## 2. Подключить расширение

Открой страницу управления расширениями:

```text
chrome://extensions/
```

В Яндекс Браузере:

```text
browser://extensions/
```

Дальше включи режим разработчика и выбери пункт загрузки распакованного расширения. В качестве папки расширения укажи:

```text
D:\уник\3 курс\2 сем\WEB\6\plagiarism-checker\chrome_extension
```

## 3. Проверить сценарий

Открой popup расширения и перейди к проверке документа. Для демонстрации можно использовать файлы из:

```text
D:\уник\3 курс\2 сем\WEB\6\plagiarism-checker\test_files
```

Рекомендуемый порядок:

```text
course_work_original.docx
course_work_similar.docx
```

После второй загрузки на странице журнала появится запись о сравнении с ранее добавленным документом. История хранится локально в IndexedDB браузера.

## Реализованные возможности

В проекте есть две страницы расширения: загрузка документа и журнал проверенных файлов. Файл отправляется на сервер AJAX-запросом, текст сравнивается алгоритмом шинглов, а клиент получает только результат анализа.

Также реализованы поля данных студента, проверка размера файла до 5 МБ, content script для страниц ВК со ссылками на `.doc`/`.docx`, локальный учет активности на сайтах и вывод статистики по текущему сайту в popup.

Интеграция с Google Drive подготовлена в коде, но в локальной конфигурации отключена. Для реальной отправки файлов требуется подключить service account Google и включить соответствующие параметры окружения.
