# Lab-rab-6 Umetskaya

Лабораторная работа 6: плагин для анализа текстов курсовых работ.

Проект состоит из трех частей:

- `chrome_extension` - расширение для загрузки документов, проверки ссылок в VK и учета активности;
- `server_node` - локальный Node.js сервер для сравнения документов по шинглам;
- `vue_source` - Vue-страницы для загрузки, списка документов и popup-панели;
- `PROJECT_NOTES.txt` - служебные заметки.

## Запуск сервера

```powershell
cd "D:\уник\3 курс\2 сем\WEB\6\plagiarism-checker\server_node"
npm install
npm start
```

Сервер доступен на:

```text
http://localhost:3000
```

## Запуск Vue-части

```powershell
cd "D:\уник\3 курс\2 сем\WEB\6\plagiarism-checker\vue_source"
npm install
npm run dev
```

## Установка расширения

1. Открой `chrome://extensions/` или `browser://extensions/`.
2. Включи режим разработчика.
3. Нажми загрузку распакованного расширения.
4. Выбери папку `chrome_extension`.

## Проверка

1. Открой страницу загрузки документов.
2. Загрузи `course_work_original.docx`.
3. Загрузи `course_work_similar.docx`.
4. Открой список документов и историю проверок.
5. Проверь popup расширения и страницу с активностью.

## Что реализовано

- загрузка `.doc` и `.docx`;
- drag-and-drop;
- сравнение текстов шинглами на сервере;
- AJAX-обмен между клиентом и сервером;
- IndexedDB для истории проверок;
- кнопка проверки рядом со ссылками `.doc`/`.docx` на страницах VK;
- учет активности пользователя на сайтах;
- popup со статистикой активности;
- локальная заготовка интеграции Google Drive через `.env`.
